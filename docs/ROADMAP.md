The features below are **not** part of PageSail v0.1 and are not offered in the app.
以下功能**不属于** PageSail v0.1，网页中也不会作为可用工具展示。
以下の機能は PageSail v0.1 には**含まれず**、アプリでも提供していません。

## Planned / 计划中 / 予定

| Area | English | 简体中文 | 日本語 |
| --- | --- | --- | --- |
| Office | Word, Excel and PowerPoint ↔ PDF conversion | Word、Excel、PPTX 与 PDF 的互相转换 | Word・Excel・PowerPoint と PDF の相互変換 |
| PDF text | Editing and reflowing text that already exists in a PDF | 直接替换和重新排版 PDF 原有正文 | PDF に元からある文字の編集・再レイアウト |
| OCR | Text recognition for scanned documents | 扫描件的文字识别（OCR） | スキャン文書の文字認識（OCR） |
| Security | True redaction, digital signatures | 安全脱敏（真正删除内容）、数字签名 | 安全な墨消し、電子署名 |
| Forms | Complex form filling and editing | 复杂表单填写与编辑 | 複雑なフォームの入力・編集 |
| Images | AI background removal, inpainting | AI 抠图、内容修复 | AI 背景除去、内容修復 |
| Collaboration | Real-time collaboration, cloud storage | 协同编辑、云端文件保存 | 共同編集、クラウド保存 |

## Smaller follow-ups / 小改进 / 小さな改善

- Opening password-protected PDFs with a user-supplied password (PDF.js supports it).
  支持输入密码打开受密码保护的 PDF。パスワード入力による保護 PDF の表示。
- Keeping bookmarks/outlines when merging or reordering pages.
  合并或重排页面时保留书签。結合・並べ替え時のしおり保持。
- Bold/italic fonts, text alignment and rich text in the annotator.
  标注中的粗体/斜体、对齐方式和富文本。注釈の太字・斜体・揃え・リッチテキスト。
- WebP/HEIC input, PDF/A output, saving editable project files.
  WebP/HEIC 输入、PDF/A 输出、可再次编辑的项目文件。WebP/HEIC 入力、PDF/A 出力、再編集可能なプロジェクト保存。
- Streaming very large exports directly to disk (File System Access API).
  超大导出直接流式写入磁盘。巨大な書き出しのディスクへの直接ストリーミング。
- Automated test runs in Firefox and WebKit; measurements on Raspberry Pi hardware.
  在 Firefox 和 WebKit 中运行自动化测试；在树莓派实机上测量。Firefox/WebKit での自動テスト、Raspberry Pi 実機での計測。
